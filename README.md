# ScoreSaber Playlist Maker

ScoreSaberのユーザーページから譜面を絞り込み、Beat Saberのプレイリストを作ります。

https://chromewebstore.google.com/detail/playlistmaker/ibjeoibpbclcpdoapiigdmjgaeplabjf

## 使い方

1. `npm install` のあと `npm run build` を実行する
2. Chromeの拡張機能画面で `dist` を読み込む
3. ScoreSaberのユーザーページを開き、ポップアップの「適用」で譜面を取得する
4. 「作成」でプレイリストを書き出す
